## Installer

1. Ouvre `Atlas-mac.zip` puis glisse **Atlas** dans **Applications**.
2. Ouvre Atlas. macOS le bloque la première fois, car il n'est pas signé par un compte développeur Apple :
   **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**, puis rouvre-le.
3. Dans **Paramètres → Modèles**, branche un modèle : ton abonnement Claude (avec Claude Code), une clé d'un service
   en ligne (Mistral, OpenRouter…) ou un modèle local (Ollama). Atlas et l'Assistant prennent le premier branché.

Atlas se met ensuite à jour lui-même : **Paramètres → Général → Mettre à jour**.

## Ce dépôt

Il ne contient pas le code d'Atlas : seulement cette page, les versions (l'app est jointe à chacune) et, dans
[`modules/`](modules/), les modules qu'Atlas propose dans **Paramètres → Modules**.
