# Modules d'Atlas

Les modules d'Atlas qui ne sont pas des outils personnels : chacun dans son dossier, avec sa fiche `module.toml` (nom, version,
version du socle demandée, programmes nécessaires). Atlas liste ce dépôt dans Réglages, Modules, Catalogue, et installe un module d'un clic.

| Module | Rôle |
|---|---|
| [`voix/`](voix/README.md) | Écoute (mot d'éveil, transcription locale) et Voix (réponses à voix haute) |
| [`pastille/`](pastille/README.md) | Une bulle flottante (macOS) qui montre qu'Atlas écoute, réfléchit ou parle quand sa fenêtre n'est pas devant |

Rien de personnel ni de secret ici : ni clé, ni jeton, ni outil lié à un compte.

## Écrire un module

Tout ce qu'il faut pour écrire un module (rangement, `module.toml`, fiches, réglages, messages échangés avec le cœur,
ce que la personne lit avant d'installer, un exemple minimal) est dans [`CONTRAT.md`](CONTRAT.md).
